# v0.2.7 Apple SDK CI 状态

v0.2.7 增加最小权限 GitHub Actions，为 Go、Swift Core 和 iOS App/Packet Tunnel Extension 提供持续构建验证。

## 已实现

- Ubuntu Go test、vet、race 和 build。
- macOS Swift Core debug/release tests。
- macOS 安装 XcodeGen并生成 `IPadProxy.xcodeproj`。
- 解析固定 Tun2SocksKit 5.16.0 package 与 checksum-pinned XCFramework。
- 使用 Apple iOS Simulator SDK 对 App 和 Packet Tunnel Extension 执行无签名 build。
- CI 权限仅为 `contents: read`。
- checkout/setup-go actions 固定到不可变 commit SHA。
- workflow 不读取、输出或上传任何环境秘密。

## CI 修复

Apple SDK 首次编译发现并修复：

- iOS 15 不支持 Duration 版 `Task.sleep(for:)`。
- 泛型 continuation value 缺少 Sendable 约束。
- Network settings、Network.framework send completion 的 Void continuation 无法推断。
- `NETunnelProviderManager` Objective-C 对象跨 continuation 的 Sendable 边界。
- MainActor manager 的 nonisolated deinit 访问非 Sendable notification token。
