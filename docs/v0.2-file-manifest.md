## Go 命令入口

### `cmd/proxy-server/main.go`

读取严格 JSON 配置，加载证书，构造 TLS 1.3 listener，启动单节点 relay，处理 SIGINT/SIGTERM 并触发优雅停止。生产可运行。

### `cmd/proxy-client/main.go`

启动仅绑定 loopback 的本地 SOCKS5 client，加载系统或指定 CA，验证服务端 hostname，连接 relay。生产可运行，但它是协议验证客户端，不是 iPad Packet Tunnel。

### `cmd/proxy-token/main.go`

使用 `crypto/rand` 生成 32 字节设备 token，同时输出客户端 token 和服务端保存的 SHA-256。输出属于秘密，不应提交或写入普通日志。

## Go 协议与网络核心

### `internal/protocol/protocol.go`

协议 v1 的唯一 Go 线格式实现：

- TLS ALPN `ipad-proxy/1`
- 4 字节大端 frame length
- 最大 body 65,600 bytes
- TCP CONNECT 与 UDP ASSOCIATE
- 32 字节认证 token
- IPv4、IPv6、domain address
- response status
- UDP datagram frame
- 严格长度、UTF-8、端口和尾随字节校验

### `internal/protocol/protocol_test.go`

验证地址往返、短读、frame 上限、request/response、非法输入和 UDP 组合大小边界。

### `internal/netutil/netutil.go`

双向 TCP relay、活动读写 deadline 和 TCP half-close 传播。两个复制方向独立运行，单方向 EOF 后关闭对端写方向。

## Go 服务端

### `internal/server/server.go`

服务端主生命周期：

- TLS 1.3 handshake
- negotiated ALPN 检查
- token SHA-256 constant-time 验证
- TCP/UDP command dispatch
- 域名解析与目标地址策略
- TCP 目标拨号和 relay
- active connection 跟踪
- shutdown timeout
- 脱敏结构化日志

### `internal/server/udp.go`

UDP association：

- TLS framing 保持 datagram 边界
- 域名/IPv4/IPv6 目标
- idle timeout
- 每 association 最多 256 个 contacted peer
- peer 60 秒无活动过期
- 只允许该 association 主动联系过的 IP:port 回包
- 达到 peer 上限后拒绝新目标

当前 UDP 运行在 TLS/TCP 上，存在 TCP head-of-line blocking；它不是 QUIC。

### `internal/server/policy.go`

服务端 SSRF/内网保护。默认拒绝 private、loopback、link-local、multicast 和 unspecified 地址，包括域名解析结果。仅开发测试可显式允许私有地址。

### `internal/server/server_test.go`

验证 token、目标策略、server 配置、UDP 回包来源限制、peer 容量和 60 秒过期。

## Go SOCKS5 客户端

### `internal/client/client.go`

SOCKS5 listener、连接生命周期、TCP/UDP command dispatch、loopback bind 校验和优雅停止。

### `internal/client/tunnel.go`

建立 TLS 1.3 tunnel，验证证书、hostname 与 ALPN，发送认证 request，读取并校验 relay response。

### `internal/client/socks.go`

SOCKS5 greeting、CONNECT/UDP ASSOCIATE request、IPv4/IPv6/domain 编解码、reply 和 UDP header 编解码。

### `internal/client/udp.go`

SOCKS5 UDP endpoint 学习与固定、TLS UDP association、FRAG 拒绝、双向 datagram 转发和 idle timeout。

### `internal/client/socks_test.go`

验证 SOCKS5 negotiation、地址、UDP header、fragment、端口编码和 loopback listener 限制。

### `internal/client/e2e_test.go`

创建本地 TLS relay、SOCKS5 client、TCP echo 和 UDP echo，端到端验证：

- token 成功与失败
- TLS tunnel
- TCP CONNECT
- TCP half-close
- UDP ASSOCIATE
- UDP datagram 边界
- UDP fragment 丢弃

## Swift 协议模块

目录：`ios/Sources/IPadProxyCore/Protocol/`

### `Address.swift`

Swift 地址模型和线格式：IPv4、IPv6、UTF-8 domain、port，包含严格长度校验。

### `Request.swift`

32 字节 `AuthenticationToken`、TCP CONNECT/UDP ASSOCIATE request、编码解码和 token 字符串/反射脱敏。

### `Response.swift`

服务端 response status、最大 512-byte message 和严格解析。

### `Datagram.swift`

UDP datagram 线格式、目标地址、payload 上限和完整 frame 上限检查。

### `FrameCodec.swift`

4 字节大端 framing；在按长度分配之前校验 1...65,600，拒绝截断与尾随数据。

### `ProtocolCodecError.swift`

协议解析的 typed errors，以及有界 `ByteReader`/`ByteWriter`。

## Swift 规则模块

目录：`ios/Sources/IPadProxyCore/Rules/`

### `RoutingModels.swift`

`DIRECT`、`PROXY`、`REJECT`，规则类型、配置错误、rule 和 destination 模型。

### `RoutingConfiguration.swift`

严格 JSON 解码、版本和 RFC 3339 时间验证、未知字段拒绝、最多 20,000 条 iOS 运行时规则。

### `IPAddress.swift`

IPv4/IPv6 文本解析、二进制形式和 CIDR prefix 匹配。

### `RuleEngine.swift`

保留文件顺序的 first-match：

- exact domain、domain suffix、port 建索引
- keyword 和 CIDR 在 20,000 上限内有界扫描
- 所有候选最终按原规则 index 选择最早匹配

### `RuleStore.swift`

规则导入和激活：

- Data/URL 输入
- 最大 32 MiB
- decode/compile 成功后才持久化
- Foundation atomic write
- 持久化成功后才交换 active snapshot
- 失败保留旧 generation
- 当前导入标记为 `localImportOnly`

## Swift Fake IP

### `ios/Sources/IPadProxyCore/FakeIP/FakeIPStore.swift`

Actor 隔离的双栈 allocator：

- IPv4 `198.18.0.0/15`
- IPv6 `fd00:198:18:2::/64`
- 保留 network/gateway/DNS host ID
- 同 domain/family 稳定映射
- 反向查询
- 固定权威 TTL
- 查询不延长 TTL
- 每族默认 4,096 条
- 不驱逐仍有效映射
- 过期地址回收
- 游标分配与回收栈
- 可注入时钟

Fake IP flow lease、correlation grace 和 reuse quarantine 已实现。生产 flow 必须持有 lease 到连接完整关闭；真实 `PacketStackAdapter` 仍待接入。

## Swift DNS

### `ios/Sources/IPadProxyCore/DNS/DNSProxyCore.swift`

DNS 核心：

- 单问题 query
- A 与 AAAA
- DNS-over-TCP framing
- PROXY 合成 Fake IP
- DIRECT 返回带 `.direct` action 的 forward decision
- 非 A/AAAA 根据规则返回带 action 的 forward decision
- REJECT 返回 REFUSED
- 接受并验证一个 EDNS(0) OPT
- 拒绝截断、尾随数据、非法 label、越界/循环/header/forward compression pointer
- 保留 transaction ID 和 RD

它不负责真实上游 socket I/O；该部分由 Packet Tunnel 集成层完成。

## Swift Transport 与路由

### `ios/Sources/IPadProxyCore/Transport/TunnelTransport.swift`

定义：

- 可取消、带背压语义的 `TCPByteStream`
- TCP write half-close
- fixed-target `UDPDatagramAssociation`
- `TunnelTransport.openTCP(to:)`
- `TunnelTransport.openUDP(to:)`

### `ios/Sources/IPadProxyCore/Routing/FlowRouter.swift`

按一次规则结果明确分派 DIRECT/PROXY/REJECT。Backend 失败原样上传，PROXY 不会静默切换到 DIRECT。

### `ios/Sources/IPadProxyCore/Configuration/CredentialStore.swift`

认证凭据抽象。生产实现不能在 error、description、log 或 reflection 中暴露 token。

## Apple-only Packet Tunnel 模板

目录：`ios/PacketTunnelTemplate/`

这些文件已通过 Swift 语法解析，但没有 Apple SDK/Xcode 类型检查和真机验证。

### `PacketTunnelProvider.swift`

- NetworkExtension 生命周期模板
- generation 隔离
- MainActor 串行状态
- start/stop 竞态处理
- 重复 stop 等待同一清理任务
- completion-once wrapper
- network settings 成功后才启动 packet reads
- IPv4/IPv6 default route
- extension DNS 地址和 `matchDomains = [""]`
- MTU 1280
- 缺少 packet stack 时 fail closed

### `NetworkFrameworkTLSTransport.swift`

- TLS 1.3 PROXY transport
- 系统 trust 和 hostname 验证
- ALPN advertisement 与 negotiated protocol 检查
- connection/TLS 和 protocol-auth timeout
- 精确 frame read
- TCP stream
- fixed-target UDP-over-TLS
- task cancellation 关闭 NWConnection

### `NetworkFrameworkDirectTransport.swift`

- DIRECT TCP NWConnection
- fixed-target DIRECT UDP NWConnection
- 建连 timeout
- UDP `receiveMessage` 保持 datagram 边界

### `KeychainCredentialStore.swift`

- Keychain generic password
- `AfterFirstUnlockThisDeviceOnly`
- app/extension 首次并发 add 的 duplicate retry
- token 读取、写入和删除
- error 不携带 token

### `AppGroupConfigurationStore.swift`

- App Group container
- 只保存非秘密 relay 和规则文件配置
- atomic write 与 complete file protection
- filename/path traversal 校验
- 不存 token
