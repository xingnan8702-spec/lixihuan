# v0.2.3 基础 iPad App 状态

当前分支：`feature/ipad-proxy-v0.2.2-local`

本轮继续使用该本地迭代分支，没有 push，也没有更新 GitHub PR。

## 已实现

- SwiftUI iPad App 入口。
- VPN 状态、relay hostname/port、token、规则导入和连接控制基础 UI。
- `NETunnelProviderManager` profile 复用、保存、reload、启动、停止和状态观察；首次加载失败可重试，App 回到 active 时重新读取系统 VPN profile。
- App 进入后台时清空尚未保存的 token 输入。
- token 严格 64 hex 校验，只保存到共享 Keychain。
- App Group 中只保存非敏感 `ProviderConfiguration`。
- Provider configuration 严格 Codable，拒绝未知字段和危险文件名。
- security-scoped JSON 规则文件导入，32 MiB 上限，失败保留旧规则。
- App 与 Packet Tunnel Extension 的 Info.plist、entitlements 和共享 capability 占位配置。
- XcodeGen `project.yml`，定义 iPad-only App 和 Packet Tunnel Extension targets。
- Extension principal class `PacketTunnelEntry`。
- Packet stack 未接入时明确 fail closed。

## 用户态网络栈决策

`docs/adr/0001-userspace-stack.md` 将 Tun2SocksKit 5.16.0/HEV 记录为后续首选 spike，但当前不下载或引入其二进制。原因是它需要 utun fd 获取和本地 SOCKS bridge，这两部分必须在 Xcode 和物理 iPad 上验证，不能在 Linux 环境中假装完成。
