# v0.2.2 实现状态

状态日期：2026-10-31

本版本分支：`feature/ipad-proxy-v0.2.2-local`

该分支名称保留 `local` 后缀以反映开发过程；当前内容已进入 GitHub 评审流程。

## 状态定义

- **可运行**：有真实入口和端到端测试，可在当前支持环境运行。
- **核心已实现**：业务状态机和边界已编码并通过 Linux 单元测试，但尚未接入 Apple Packet Tunnel。
- **Apple 模板**：代码已提供并通过 Swift 语法解析，但没有 Apple SDK/Xcode 类型检查和真机证据。
- **未实现**：仓库中没有完整实现，不能作为已有能力使用。

## 一、可运行并已测试

### Go relay server

状态：**可运行**

已实现：

- TLS 1.3 listener。
- ALPN `ipad-proxy/1`。
- 32-byte token 认证，服务端保存 SHA-256 digest 并 constant-time compare。
- TCP CONNECT。
- UDP ASSOCIATE，保持 datagram 边界。
- IPv4、IPv6、domain target。
- TCP half-close。
- 默认拒绝 private、loopback、link-local、multicast 和 unspecified destination。
- 总 session、并发 handshake、UDP association 和 UDP contacted peer 上限。
- UDP peer 过期和未联系端点回包拒绝。
- shutdown deadline、active socket registry 和 UDP pump join。
- 不包含 token、payload 和完整目标的聚合指标。

### Go SOCKS5 client

状态：**可运行**

已实现：

- 仅 loopback listener。
- SOCKS5 CONNECT。
- SOCKS5 UDP ASSOCIATE。
- IPv4、IPv6、domain address。
- TLS 证书、hostname 和 ALPN 验证。
- SOCKS5 UDP FRAG 拒绝。

### 协议兼容

- `testdata/protocol-v1.json` 是唯一 golden fixture。

## 二、Swift 核心已实现

### 协议 codec

状态：**核心已实现**

- 4-byte big-endian frame。
- 最大 body 65,600 bytes。
- Address、Request、Response、Datagram。
- 严格版本、长度、UTF-8、端口、尾随数据检查。
- token description、debug 和 reflection 脱敏。

### 规则引擎

状态：**核心已实现**

- JSON 导入，不内置规则数据。
- domain、domain_suffix、domain_keyword、IPv4/IPv6 CIDR、port、FINAL。
- DIRECT、PROXY、REJECT。
- 文件顺序 first-match。
- exact domain、suffix 和 port 索引。
- 最多 20,000 条 iOS runtime 规则。
- 规则输入最大 32 MiB。
- 校验/编译/持久化成功后才切换 active generation。
- 失败保留旧规则。

### Fake IP

状态：**核心已实现**

- IPv4 `198.18.0.0/15`。
- IPv6 `fd00:198:18:2::/64`。
- domain/family 稳定映射和反查。
- 固定 DNS TTL，不因普通查询或反查滑动。
- correlation grace。
- flow lease。
- reuse quarantine。
- lease identity 防止重复 release 和 ABA 地址复用错误。
- pool 内未知 Fake IP 与普通公网 IP 明确区分，未知 Fake IP fail closed。
- 每族容量和 pool exhaustion。

### DNS core

状态：**核心已实现**

- UDP DNS message 和 DNS-over-TCP framing。
- 单 question A、AAAA。
- PROXY A/AAAA 合成 Fake IP。
- DIRECT/PROXY action-preserving forwarding。
- REJECT 返回 REFUSED。
- HTTPS/SVCB 等其他 qtype 不伪造。
- 一个 EDNS(0) OPT。
- 压缩指针循环、越界、header/forward pointer 拒绝。
- 上游 response transaction ID、QR、opcode、question、qtype、qclass 和 record 边界验证。

### DNS upstream service

状态：**核心已实现，生产 adapter 未接入**

- DIRECT 和 PROXY resolver 完全分离。
- 任何错误和 timeout 都不在两条路径间 fallback。
- 默认 upstream timeout 5 秒。
- 默认最多 256 个 inflight query。
- 超限不调用 resolver。
- UDP TC 响应沿相同 action 用 TCP 重试一次。
- TCP 仍返回 TC 时明确失败。
- TCP 入口固定走 TCP upstream。
- timeout 取消 resolver task，resolver 退出后才归还 permit。

### 受管 flow

状态：**核心已实现，PacketStack 尚未接入**

- opening permit -> route/open -> active permit。
- Fake IP flow 原子取得 lease，恢复 domain 和原 port。
- pool 内未知 Fake IP fail closed。
- backend open 或 activate 失败时释放所有资源。
- TCP/UDP wrapper 在 EOF、I/O error 和 close 时幂等 cleanup。
- TCP half-close 成功时不提前释放 flow。
- `ManagedFlowRegistry` 强持有活动 flow。
- tunnel stop 可调用 `closeAll()` 回收 owner 遗忘关闭的 flow。
- 并发 closeAll、单 flow close、EOF 和 error 只清理一次。

### 有界资源

状态：**核心已实现**

- item/byte 双上限 FIFO queue。
- 有界等待 consumer。
- finish、cancel 和 cancellation-safe dequeue。
- current/high-water/rejected metrics。
- opening flow 默认 128。
- active flow 默认 1,024。
- active UDP 默认 256。
- 不可伪造 permit 和幂等 release。

### 生命周期控制

状态：**核心已实现，Apple bridge 尚未使用**

- stopped、starting、running、stopping、failed。
- 单调 generation。
- stop-during-start。
- 启动失败回滚。
- fatal error 与 stop 共用 cleanup gate。
- 默认 5 秒 cleanup timeout。
- residual resources 阻止 restart。
- cleanup retry。
