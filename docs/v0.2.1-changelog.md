# v0.2.1 稳定性加固

## 目标

在接入真实 lwIP/Packet Tunnel 前固定资源所有权、容量和跨语言协议兼容性，不增加新传输协议。

## Swift core

- Fake IP 映射新增 flow lease、60 秒 correlation grace 和 60 秒 reuse quarantine。
- lease 通过 store/mapping/lease identity 校验，重复或迟到 release 不影响新映射。
- 新增 item/byte 双限制的 `BoundedByteQueue`。
- 新增 opening 128、active 1024、UDP 256 默认上限的 `FlowLimiter`。
- 新增平台无关 `TunnelLifecycleController`，覆盖 startup rollback、stop 合并、fatal cleanup、5 秒 cleanup timeout 和 residual restart block。

## Go relay

- 总 TLS session 默认上限 1024。
- 并发 TLS/协议认证握手默认上限 64。
- UDP association 默认上限 256。
- 达到上限时 non-blocking 拒绝，不建立无界 goroutine 队列。
- UDP 两个 pump 在 association 返回前完整 join。
- shutdown registry 在锁外关闭 socket。
- 新增不含 token 和目标的聚合 metrics snapshot。

## 协议兼容

`testdata/protocol-v1.json` 由 Go 与 Swift 同时读取，覆盖 TCP/UDP request、response、IPv4、IPv6、UTF-8 domain 和 datagram exact wire bytes。

## 未改变的边界

- 尚无真实 lwIP/PacketStackAdapter。
- 尚无 Xcode containing app/extension targets、entitlement、签名和真机证据。
- UDP 仍通过 TLS/TCP，存在队头阻塞。
- QUIC 不属于 v0.2.1。
